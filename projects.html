Network Systems & Cryptographic Security

CryptShield — Java AES Socket Chat Application

Military-grade symmetric payload encryption with multi-threaded socket concurrency
GitHub Code

Designed to guarantee uncompromised end-to-end confidentiality in insecure network environments. Built completely from the ground up in Core Java, CryptShield leverages native socket programming and the Java Cryptography Architecture (JCA) to ensure zero plain-text leaks across wire transmissions.

Key Capabilities & Architecture

  • ✓ AES Symmetric Encryption: All message packets are encrypted on the client before network dispatch and decrypted only upon arrival by authenticated receivers.
  • ✓ Multi-Threaded Server Architecture: Java `ServerSocket` and thread pools handling concurrent client connections with independent I/O streams.
  • ✓ Tamper-Resistant Authentication: Handshake protocol validating client identity prior to granting access to communication channels.
  • ✓ Zero Raw Text Footprint: Server acts as an agnostic cipher broker, incapable of reading or storing conversational payloads.

AgriConnect — AI Farmer-to-Buyer Direct Market

Disintermediating agricultural supply chains with Google Gemini AI intelligence
GitHub Code

Smallholder farmers face severe margin cuts due to multi-layered brokers and lack of real-time price transparency. AgriConnect delivers a direct peer-to-peer commerce platform connecting agrarian producers directly with wholesale and retail buyers, powered by real-time AI advisory.

Key Capabilities & Architecture

  • ✓ Google Gemini AI Advisory: Integrated Gemini API to process natural-language and visual queries for crop disease diagnosis, yield estimates, and prevailing market rate suggestions.
  • ✓ Direct Peer-to-Peer Messaging: Integrated in-app and WhatsApp messaging hooks allowing farmers to negotiate and close deals without third-party commission deductions.
  • ✓ Live Commodity Catalog: Real-time listing of produce categories, quantities, harvest dates, and regional geolocation filtering.
  • ✓ Lightweight & Mobile Responsive: Optimized for low-bandwidth rural connectivity environments with rapid DOM rendering.
